# 音芽 v0.21.0 · 段落衔接

为相邻两段搭配过门，连续听完八小节，再决定是否应用。

- **三种过门**：轻柔过渡修改前段末两拍；推进进入修改前段末一小节；留白呼吸让前段末拍休止。三者只改前段对应范围与后段首拍的三行鼓点和逐击力度。
- **可选音量衔接**：逐声部选择，两端平均、沿用前段结束值或沿用后段起始值。连接前段结束与后段起始音量，保留前段起始、后段结束值；界面明确说明渐变影响前后各四小节。
- **连续八小节比较**：原版／候选使用相邻两段实际四声部，显示前后段播放进度，段间自然衔接，八小节后保留自然余音。前段静音、后段有声时也可试听。
- **确认后应用**：显示具体鼓点改动范围、力度变化及音量接点；候选固定，关闭或取消保留原稿。应用前确认，过期确认拒绝，一次撤销／重做恢复两段。
- **保持作品兼容**：沿用 v16 作品格式和存储键，与 v0.18／v0.19／v0.20 互读。旋律、和弦、贝斯音符、音色、鼓组、声部开关与整曲音量保留，仍支持完整 4–32 小节 WAV／MP3 导出。

387 项测试通过（新增 21 项），静态包构建与隐私检查通过。覆盖全部相邻边界、局部鼓点、音量策略、保存分享往返、事务保护、双采样率连续试听，以及衔接后 32 小节 WAV 和独立 MP3 解码。

首版支持两个相邻四小节段，至少需要八小节。音量接点一致不代表音色或声部开关相同；按原有配器试听后选择。实体手机听感与长曲性能仍需后续验证。
