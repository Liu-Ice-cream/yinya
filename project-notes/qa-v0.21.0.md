# v0.21.0 段落衔接验证

日期：2026-10-30。

## 实现范围

- 新增 `transition.js` 的本地固定规则和 `transition-workshop.js` 候选界面。由相邻段落对选择前段索引，不接受非相邻拼接或首尾环接；单个四小节作品提示先新增段落。
- 轻柔过渡修改前段最后两拍，推进进入修改前段最后一小节，留白呼吸清空前段最后一拍；都只改后段首拍，后段第 2 拍起及前段范围以外原样保留。
- 三行鼓点的音量独立，移除的鼓点恢复标准空拍元数据。原有旋律、和弦、贝斯全部数据、音色、鼓组、段落开关与整曲设置保留。
- 音量衔接可单独使用，按声部勾选，提供两端平均（取整至 1%）、沿用前段结束、沿用后段起始。只写前段结束与后段起始值；前段起始、后段结束及其他段落保留，线性渐变作用于前后各四小节。用户界面及确认提示明确此范围。
- `rangeState` 扩展原有单段切片，保留每种表达元数据及本段配器；`playRange` 连续渲染八小节，包含段间换音色、动态和静音，最后只添加一次自然余音。可听判断覆盖全部八小节，不因前四小节静音而漏掉后四小节。
- 共用试听取消机制，参数变化、停止、关闭、Esc、切后台或开始其他播放取消旧请求；前／后段进度以实际播放时间推进，自然结束恢复按钮和进度。应用前确认，作品或候选过期拒绝，整次写入历史并可一次撤销／重做。
- v16 格式、`yinya.v16.*` 存储键与数据模型未修改；候选、进度及对比选项不写入作品。
