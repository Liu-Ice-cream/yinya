# 音芽 v0.1.1

日期：2026-10-06。

## 功能变化

增加「导出 MP3」与「下载 MP3」入口，导出当前作品的完整四小节，格式为 44.1 kHz、192 kbps 立体声。保留 WAV 导出，下载按钮明确标注当前格式。

MP3 编码在 Web Worker 中执行，显示合成及编码进度。编码器随项目保存，无需 CDN、上传音乐或外部编码服务；两种格式均支持取消导出。运行期间禁止重复启动导出，失败或取消后可重试，作品及此前成功生成的下载链接保留。

版本号更新为 0.1.1。作品 v1 格式、草稿及作品库的存储键保持兼容。

## 验证

- `npm run build-yinya` 通过，生成界面及独立 MP3 Worker。
- `npm run test-yinya`：10 项全部通过。新增测试用真实 BeepBox 四小节 PCM 编码，再用独立 mpg123 WASM 解码器验证 MP3；逐帧核对 192 kbps、44.1 kHz、立体声与完整帧结构。
- 覆盖不足 1152 采样的末尾块、非相同左右声道、静音、采样削波、无效输入，以及分发模块与固定版本依赖的一致性。
- 真实浏览器下载 MP3：120 BPM，193097 字节，2 声道，44100 Hz，354816 解码采样，约 8.045714 秒，解码无错误，末尾仍有音频。原始音乐为 8 秒，余量为 MP3 编码延迟及补齐；详见 `mp3-v0.1.1-validation.json`。
- 真实浏览器下载 WAV：2 声道，44100 Hz，16 位，352800 帧，8 秒；Python wave 模块读取验证通过。
- 真实浏览器验证：导出中禁用两种导出按钮；取消后恢复按钮、保留前一次下载链接；WAV 与 MP3 可连续导出；未观察到控制台错误或警告。
- 390 × 844 视口下，新增导出入口与下载链接正常换行，页面无横向溢出。截图：`yinya-v0.1.1-mp3.jpg`、`yinya-v0.1.1-mobile.jpg`。

本版未执行人工听感评分、实体手机及多浏览器长期测试。其他功能范围延续 [v0.1.0](release-v0.1.0.md)。
