# 音芽 v0.9.0 · 自由旋律

把旋律从五声音阶扩展到完整大调与自然小调，搭配两个八度的音域和更丰富的和声，继续保持点格子创作。

- 五声音阶继续保留，新增完整大调、自然小调。切换音阶保留已有音符，并标记音阶外音。
- 旋律与贝斯覆盖两个八度，提供低／高／完整音域与唱名／实际音名视图；显示范围外的已有音符会提示。
- 整曲可升降 12 个半音，同步旋律、和弦、贝斯，鼓点不变。当前小节或四小节段还可单独移动旋律／贝斯八度；任一音符越界时整次拒绝，保留时长、力度与原内容。
- 19 组和弦、按音阶推荐或完整和弦库、6 种四小节走向。模板只覆盖本段和弦，覆盖提示并可撤销，填入后继续逐拍编辑。
- 新四音 G7 在全部五种伴奏中奏出第七音，并校准叠音能量；原有四组和弦保持原来的排列与演奏。
- 新增原创十六小节示例「风中明信片」「暮色小径」。

作品格式升级为 v10，兼容读取旧 v1–v9。旧音高 ID 与四组和弦固定保留，默认五声音阶及原调，旧作品音色、力度、时长和段落安排保持。新草稿与作品库使用 `yinya.v10.*`，保留旧存储键。旧版无法读取新 v10 作品，回退前请保留 JSON 备份；备份上限继续为 64 KB。

115 项自动测试通过，包括冻结 v0.7.0／v0.8.0 转换基准、25 种整曲移调、音域边界原子拒绝、六种模板仅覆盖目标、全部和弦／音色／伴奏通过实际解析器、最高最低音试听、试听与导出 PCM 对照，以及移调后的 32 小节 WAV／MP3 与独立解码。

桌面浏览器验证了旧草稿／作品库迁移、音阶外音保留、视图提示、八度移动与越界拒绝、模板取消／确认／撤销／重做、新音符试听、段落循环中的移调、保存刷新、分享重开及完整十六小节双格式导出。390 像素视口的旋律、和弦与调性面板无整页横向溢出，网格可在内部滚动。详见 `project-notes/browser-v0.9.0-validation.json` 与截图。

长音仍限于单个小节，各段共用整曲音色、调性与速度。和弦模板不会自动改写贝斯；真实乐器采样、实体手机及更多浏览器的长曲性能仍待后续验证。
