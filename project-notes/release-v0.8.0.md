# 音芽 v0.8.0 · 灵动节拍

用鼓点模板、分段伴奏、贝斯音色和音符力度，让同一首曲子拥有更丰富的演奏变化。

- 六种原创鼓点模板：轻快流行、舒缓步伐、电子四拍、像素跳跃、轻盈切分和半速律动。可填入当前小节或当前四小节段，并在最后一小节加入过门；覆盖提示、撤销与逐格修改完整接通。
- 和弦新增轻扫弦、跳跃短奏和舒展分解，与原齐奏、分解共五种。每段可独立选择或跟随整曲，音符、音色及空拍保留。轻扫弦以低音、两音、三音逐层加入形成合成效果。
- 贝斯可独立选择复古方波、柔和合成贝斯或拨弦风格贝斯；新音色调校伴奏强度，并在自然收尾时保留需要越过曲尾的余音。
- 旋律和贝斯支持轻／标准／重三档力度，选中后调整整个长音，未选中时设置新音符；色块深浅与无障碍名称同时标记。复制、重排、保存、分享、试听及 WAV／MP3 保留力度。
- 新增「晴窗律动」「夜航微光」「像素漫游」三首原创十六小节示例。

作品格式升级为 v9，兼容旧 v1–v8。保留原有音色、演奏、长短音与段落开关，旧贝斯继续使用方波，力度默认标准，各段伴奏默认跟随整曲。新存档使用 `yinya.v9.*`，保留旧存储键。旧版无法读取新 v9 作品，回退前请保留 JSON 备份；备份上限继续为 64 KB，支持完整 32 小节作品。

99 项自动测试通过，包括冻结 v0.7.0 的旧转换结果、迁移、模板范围与过门、伴奏经过真实解析器后不丢音、三档力度可辨性、贝斯全部音高和时长、采样率及速度边界、试听与导出对照、自然曲尾、32 小节 WAV／MP3 及独立解码。

桌面浏览器验证覆盖取消与撤销、复制重排、力度显示、新示例播放、保存刷新、分享设置、完整 32 小节双格式导出及取消。390 像素布局无整页横向溢出，音符网格可横向滚动。

当前电脑的代表性 Node 导出基准：32 小节、60 BPM、四声部及混合力度、每拍扫弦，128.33 秒音乐合成约 2.5 秒，MP3 编码约 9.4 秒；输出 WAV 约 22.6 MB、MP3 约 3.1 MB。进程采样峰值约 371 MB，含运行时和保留的中间结果；不是浏览器或实体手机内存指标，也不是最坏情况上界。详见 `project-notes/performance-v0.8.0.json`。

音色继续采用合成声音。长音仍限于单个小节，每段共用整曲音色与速度；实体手机及更多浏览器的听感和长曲性能仍待验证。
