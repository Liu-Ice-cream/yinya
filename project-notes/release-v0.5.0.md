# 音芽 v0.5.0：同一组和弦，两种弹法

和弦层新增「演奏方式」：齐奏或分解。齐奏每拍同时响三音；分解按低 → 中 → 高 → 中，每拍依次弹出四个十六分短音。圆润波形、钢琴、电钢琴、木吉他均支持，原有空拍和所选和弦保留。

- 点击和弦试听完整一拍分解，当前四小节「旋律＋和弦」试听同步使用所选演奏方式。
- 切换可撤销／重做，切换时停止旧试听；播放、存档、分享、JSON 备份和 WAV / MP3 均保留演奏选择。
- 新乐器继续保留曲尾释放，整段循环和圆润波形保持小节长度。
- v6 格式使用固定演奏修订 ID，旧 v1–v5 默认齐奏，保留 v5 和弦音色、v4 旋律及 v3 长音。新存档使用 `yinya.v6.*`，保留旧存储键。旧版无法读取新 v6 作品，回退前请保留 JSON 备份。

62 项自动测试通过，包含全部和弦音色与形状、四个短音的顺序和时序、独立合成器试听对照、速度与采样率边界、迁移、快照与取消、自然余音，以及十六小节 WAV / MP3 和独立解码。浏览器验证演奏切换、撤销重做、点击／段落试听、保存刷新、分享、导出与手机宽度布局。

分解目前为整条和弦轨使用固定节奏；按段切换、扫弦及更多节奏留作后续。乐器继续使用合成预设，实体手机和更多设备听感仍需后续验证。
