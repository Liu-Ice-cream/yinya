# v0.19.0「整曲编排台」验证记录

日期：2026-10-23。

## 自动验证

- `npm run test-yinya`：346 项通过，零失败；新增 19 项编排验证，原有 327 项继续通过。
- `npm run package-yinya`：构建和静态网站包通过。
- 四种声部的四小节快照包含全部音符、旋律／贝斯时长与力度、和弦时长与转位／力度、三行独立鼓点力度。跨小节长音随完整四小节移动，数组不共享。
- 默认粘贴只改变目标声部音符；可选配器复制只改变该声部本段的加入状态、音色或鼓组、和弦演奏方式、起止音量。其他声部、其他段落、段名、整曲音色／音量／调性／速度保留。
- 来源后续变化及段落重排不改写剪贴快照。缺失、稀疏、越界、重叠或越过段末的剪贴数据原子拒绝。
- 覆盖确认前不改写，空白来源清空前提示，取消／过期／导出期间拒绝旧操作，确认只提交一次；空目标可直接应用。
- 总览使用实际本段音色、鼓组、演奏方式、加入与静音原因及起止音量；缩略图覆盖长音、转位叠音及独立鼓击，坐标限制在本段范围内。
- 组合快照保留全部本段表达、动态、开关及音量，只临时过滤试听声部；空白或静音组合不开音频上下文。快速切换取消旧权限等待，停止或自然结束恢复状态，错误可重试。
- 44.1／48 kHz 的旋律＋和弦、贝斯＋鼓点及单和弦试听，与独立 AudioRenderer 的双声道 PCM 逐采样一致；试听前后完整作品的音频转换结果相同。
- 沿用 v16 格式，保存、分享与备份保留结果，不加入总览／剪贴／试听会话字段；所有旧作品冻结转换、长音及 32 小节 WAV／独立 MP3 解码回归继续通过。

## 浏览器实测

- 从「主题」鼓点格进入正确的第 5–8 小节鼓点编辑台，再返回总览，当前格与范围提示一致。
- 复制前奏旋律到结尾：覆盖提示指明目标与声部；取消后分享快照完全相同。应用后仅目标旋律改变，其他三个声部及全部本段配器逐项比较相同；一次撤销恢复完整原稿。
- 勾选配器复制时，目标旋律从原有配器改为前奏电钢琴及 85% 音量，其余声部和整曲音色保持；撤销恢复。
- 旋律＋和弦试听可启动，完成后按钮复原，分享作品快照与原稿一致。关闭的结尾鼓点在「仅所选声部」模式下禁止试听，并显示静音／内容检查提示。
- 390 × 844 窄屏：页面无横向溢出，总览独立横向区域宽 680px、可见 295px；方向键验证实际横向偏移，声部标签固定在左侧。远端段落可进入编辑并返回。视口已重置。
- 21 项已有本地作品保留；新增「晨光接力 · 整曲编排」验证作品后为 22 项。32 小节保存重载，显示 8 段 × 4 声部共 32 格，剪贴与组合选择刷新后清空。
- 选择单声部试听组合后启动导出，界面仍按完整 32 小节导出，导出期间编排复制禁用。文件格式与收尾由完整音频自动回归验证。

## 范围

总览是导航与片段复用入口，不是任意音符拖放时间线。每段固定四小节，总长仍为 4–32 小节；组合试听限定当前段并尊重静音。剪贴快照仅保留在当前页面，刷新后清空。作品格式与 v0.18.0 相同。实体手机、多浏览器及长期播放性能仍待更多设备验证。
