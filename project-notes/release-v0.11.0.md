# 音芽 v0.11.0 · 旋律工坊

在当前四小节写一句旋律，比较几个候选，再继续改成自己的音乐。

- 三种创作方式：生成四小节、保留前两小节续写后半句、保留节奏改音高。续写保留原句全部数据；改音高保留所有起点、休止、时长和力度。
- 舒缓、轻快、跳跃三种风格，疏／中／密及低／高／完整两八度。规则依据当前音阶与和弦，重拍优先和弦内音，安排短句重复与句尾收束。
- 固定候选与「换一版」、原版／候选四声部试听、音符数量摘要、无和弦／无共同音／静音提示、覆盖取消和确认，以及整次撤销重做。
- 可选择在本段开启旋律；伴奏、其他段落及整曲音色、音量、速度和调性保留。应用后定位到首个改动小节，可继续逐格编辑。

生成与合成均在本地完成，不调用外部生成服务。继续使用 v10 格式及原存储键，兼容旧 v1–v10；v0.9.0、v0.10.0 与本版可互相读取生成后的普通音符。已存作品不会自动改编，修改和弦后可按需重新生成旋律。

157 项自动测试通过，新增 21 项旋律测试：三种风格／密度／音阶／音域组合、19 组和弦、无共同音回退、短句重复、确定性候选、原句／节奏及伴奏保护、25 种移调、冻结 v0.10.0 转换基准、异步试听取消、生成旋律后的 32 小节 WAV／MP3 与独立解码。四声部 PCM 对照先预热共享波形，在隔离测试中为两次渲染使用相同随机种子，产品声音参数不变。

浏览器验证覆盖试听前后快照一致、换版、三种生成方式、覆盖取消与确认、精确撤销重做、空白引导、Esc 停止、保存刷新及分享重开，以及完整 32 小节 WAV／MP3 生成与取消。390 × 844 窄屏没有整页或工坊横向溢出，滚动后可完成应用与覆盖取消。详见 `project-notes/browser-v0.11.0-validation.json` 及截图。

本轮仅生成当前四小节段，长音仍限于单个小节；各段共用整曲音色、速度与调性。规则提供创作候选，不保证每版都符合个人听感。实体手机及更多浏览器的长曲性能仍需后续验证。
