# 音芽 v0.17.0 · 和声工坊

和弦可以连续编辑四小节，每拍独立设置转位与轻重，并通过平滑连接候选调整伴奏的衔接。

- 新增 16 拍和弦编辑台，支持框选、多选、复制粘贴、拖动／按钮移动、批量替换与删除。冲突或越界整次取消，每次可一次撤销，手机可滑动并用按钮操作。
- 原位、第一／第二转位，以及四音和弦的第三转位；逐拍轻／标准／重力度。分解和扫弦按新的音高排列发声，保留全部音。单小节视图点已有和弦选中，可调整或删除。
- 和声工坊保留当前和弦种类和空拍，提供平滑连接、保持转位、恢复原位及轻重候选；比较完整四声部的原版与候选，取消保留原稿，应用后一次撤销。
- 新增「和光流转」「晚风和声」示例。保存、分享、段落复制和 WAV／MP3 均保留逐拍转位与力度。

平滑连接使用四小节内的规则辅助：保留第一组和弦当前转位，以声部音高移动距离选择后续转位；不跨段连接，不改变旋律或贝斯。

作品格式升级为 v15，读取旧 v1–v14 并保留旧存储键及原有声音；旧和弦默认原位、标准力度。v0.16.0 及更早应用不能读取 v15，请保留旧版备份。JSON 备份上限仍为 96 KB。

验证：307 项自动测试，包括冻结旧作品转换、原子编辑与指针取消／过期保护、穷举对照的连接选择、全部和弦及转位、双采样率实际合成、32 小节 WAV／MP3 与独立解码。桌面和 390px 窄屏交互验证；实体手机及更多浏览器的长曲性能仍需继续验证。
