# 音芽 v0.7.0：从循环片段到段落编曲

现在可以把四小节片段编排成有前奏、主题、变化和结尾的小曲。

- 每段固定四小节，可命名、复制为独立新段、新增空白、前后移动及删除；四声部、长音和段落设置一起移动，支持撤销和重做。
- 每段独立安排旋律、和弦、贝斯和鼓点是否加入。关闭声部保留音符，仍可编辑；整曲开关及音量继续生效。
- 固定循环所选段落，手动查看其他段不改变循环范围；也可从本段开头播放至整曲结尾一次。WAV / MP3 始终导出全部段落。
- 支持 4–32 小节的全部四的倍数，120 BPM 下为 8–64 秒。新增十六小节原创示例「林间来信」。
- v8 作品格式兼容旧 v1–v7，按原版本迁移音色、演奏方式和长短音；新增段落默认加入全部声部。新存档使用 `yinya.v8.*`，保留旧键。旧版无法读取新 v8 作品，回退前请保留 JSON 备份；导入上限为 64 KB。

84 项自动测试通过，包括段落校验、重排及深复制、静音保留音符、旧格式迁移、固定循环、一次播放、试听、32 小节 WAV / MP3 与独立解码、自然曲尾和取消。桌面浏览器验证编辑、删除取消和撤销、保存刷新、分享、32 小节双格式导出、导出取消及 390 像素布局。

当前电脑的 Node 基准：32 小节、60 BPM、四声部全部加入，128 秒音乐合成约 2.1 秒、MP3 编码约 14.4 秒；输出 WAV 约 22.6 MB、MP3 约 3.1 MB。进程采样峰值约 377 MB（含运行时及保留的中间结果），不是浏览器或实体手机的内存指标，详见 `project-notes/performance-v0.7.0.json`。

每段共用整曲音色与速度，旋律和贝斯长音仍限于单个小节。实体手机和更多浏览器的长曲导出性能继续留待验证。
