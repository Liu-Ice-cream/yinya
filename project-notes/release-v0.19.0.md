# 音芽 v0.19.0 · 整曲编排台

把旋律、和弦、贝斯与鼓点放到同一张整曲总览里，更容易安排前奏、主题、变化与结尾。

- 四声部 × 段落总览，显示音符缩略图、实际音色、加入或静音原因、本段音量与和弦演奏方式。点击一格直达对应四小节编辑台，可返回总览；支持键盘和窄屏独立滚动。
- 复制某一声部的四小节快照到其他段，保留长音、力度、和弦转位或独立鼓点表达。默认保留目标配器，也可选择一并复制该声部的本段配器；覆盖前提示，取消保留原稿，应用后一次撤销。
- 当前段可选择四声部、旋律＋和弦、贝斯＋鼓点或仅所选声部试听，按已有开关与音量发声。试听组合不写入作品，主播放及 WAV／MP3 保留完整编曲。

沿用 v16 作品格式和存储键，与 v0.18.0 互读；仍为 4–32 小节、每段四小节。剪贴片段和试听组合仅存在当前页面，不随作品保存。
