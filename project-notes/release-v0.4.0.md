# 音芽 v0.4.0：旋律与和弦，搭配自己的声音

和弦可以独立选择圆润波形、钢琴、电钢琴或木吉他，与六种旋律音色自由搭配。当前四小节试听可选「仅旋律」或「旋律＋和弦」，比较伴奏搭配，保留原有音符、三音和声及节奏。

- 单独校准和弦发音强度，新和弦点击试听一拍与余音。
- 双声部试听尊重各层开关和音量；模式切换、编辑或完整播放、导出会取消旧试听。
- 自然收尾同时照顾旋律和和弦余音；整段循环保持小节长度，WAV / MP3 使用同一套乐器定义。
- v5 格式记录独立和弦音色，兼容旧 v1–v4。v4 旋律声音和长音保持不变，新存档使用 `yinya.v5.*`，保留旧存储键。旧版本无法读取新 v5 作品，回退前请保留 JSON 备份。

54 项自动测试通过，包括所有和弦形状、音色组合、速度和设备采样率边界、伴奏能量、试听静音与取消、曲尾及十六小节 WAV / MP3 独立解码。浏览器验证音色切换、撤销重做、双声部试听、存档、分享、导出及手机宽度布局。

新乐器均为合成音色，未引入录音采样包。木吉他目前同时拨响三音，扫弦和分解和弦留待后续。能量校准不等于所有设备上的主观听感一致；实体手机与更多设备试听仍需后续验证。
