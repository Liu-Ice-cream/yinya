# 音芽 v0.3.0：同一段旋律，六种声音

旋律新增钢琴、电钢琴、木吉他合成音色，保留柔软三角波、圆润波形与复古方波。点「试听这段旋律」听当前四小节的旋律，再切换音色比较；音符、长音和其他声部不变。

- 校准新音色的发音强度，处理长短音和释放时间。
- 试听支持停止；切换声音、编辑、切换小节或开始完整播放、导出时取消旧试听。
- WAV / MP3 支持自然收尾，按需要保留曲尾余音；也可选整段循环，保持小节长度。
- v4 作品格式用固定音色 ID 保存声音，兼容旧 v1 / v2 / v3 的存档、链接和备份。旧波形与 v3 长音保持不变，新存档使用 `yinya.v4.*`，保留旧存储键。旧版本无法读取新 v4 作品，回退前请保留 JSON 备份。

44 项自动测试通过，包含所有旋律音高、长短音、速度与设备采样率边界、能量校准、段落试听取消、曲尾释放、十六小节 WAV / MP3 与独立 MP3 解码。浏览器验证音色切换、撤销、试听、存档、分享、导出和窄屏布局。

三种新乐器均为合成预设，未引入录音采样包。能量校准不代表不同设备上的主观听感完全一致；实体手机与更多设备试听继续留作后续验证。
