# 音芽 v0.20.0 · 主题变奏

把同一个主题，写成新的回应。选一个已有四小节旋律作为来源，生成候选并应用到目标段，让重复的主题有小幅变化。

- **三种变奏**：轻微修饰调整少量音高；节奏变化移动起点、拆成同音短句或缩短留白；结尾收束参考目标和弦调整末尾音符。
- **保护主题**：可保留来源前两小节及每小节第 1、3 拍起音；跨入后半句的受保护长音也完整保留。可改音符参考目标和弦与创作音阶，受保护音符始终优先。
- **比较再应用**：展示来源、目标原版和目标候选的旋律轮廓及改动数量；三者均可试听实际四声部。候选保持固定，轻微修饰及节奏变化可「换一版」。
- **覆盖与恢复**：只替换目标段旋律；和弦、贝斯、鼓点及本段配器保留。默认保留声部开关，可显式加入目标旋律层。覆盖前提示，取消保留原稿，应用可一次撤销、重做，过期确认拒绝。
- **兼容保存与导出**：沿用 v16 格式和原存储键，与 v0.18／v0.19 互读，变奏结果是普通可编辑音符；保存、分享、JSON 备份及完整 4–32 小节 WAV／MP3 都保留结果。

366 项测试通过（新增 20 项），静态网站包构建和隐私检查通过。覆盖长音保护、跨段隔离、音域与冲突、候选事务、双采样率试听 PCM 对照，以及变奏后 32 小节 WAV 和独立 MP3 解码。桌面及 390px 窄屏验证了候选、覆盖取消、应用、撤销、保存重载和试听结束。

这是本地规则辅助，旋律是否合适仍需试听选择。首版只处理旋律，长度保持每段四小节；实体手机听感与性能仍需更多验证。
