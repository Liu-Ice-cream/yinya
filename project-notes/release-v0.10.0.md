# 音芽 v0.10.0 · 伴奏工坊

写好旋律后，为当前四小节配上贝斯或成套伴奏，先比较原版与候选，满意后再应用。

- 按本段和弦生成三种贝斯：平稳长音、根音交替、八度律动。换和弦时换音，减和弦与旧和弦排列使用自身音符，首个和弦之前和空白小节留白。
- 三套组合：轻快流行、温柔抒情、电子律动，搭配不同和弦演奏、贝斯节奏与鼓点，并在最后一小节加入过门。
- 可单独选择要改动的和弦、贝斯、鼓点。和弦默认沿用本段音符；明确选择采用风格走向时，才按当前音阶填入和弦。旋律、其他段落及整曲音色、音量、速度、调性保留。
- 可以在本段开启所选声部，整曲静音和音量仍生效；候选摘要说明实际改动与静音情况。
- 原版／候选四声部试听、停止、切换与取消；候选尚未应用时不写入草稿。覆盖已有内容前确认，支持整次撤销、重做，应用后仍能逐格编辑。

生成与合成均在本地完成，不依赖外部生成服务。继续使用 v10 作品格式和原有存储键，兼容旧 v1–v10；本版的生成结果是普通音符，v0.9.0 也可读取。旧作品不会自动改编，修改和弦后需要时可重新生成贝斯。

136 项自动测试通过，包含此前 115 项及 21 项伴奏验证：19 组和弦及三种贝斯、全部非空声部组合、生成范围与设置保护、休止和和弦变化、快照与异步试听取消、静音、冻结 v0.7.0／v0.8.0／v0.9.0 兼容基准，以及生成伴奏后的 32 小节 WAV／MP3 与独立解码。鼓点和拨弦声音具有随机相位，四声部音频按事件、时长、有限采样及能量对照，确定性贝斯另做 PCM 对照。

浏览器验证覆盖原版／候选试听后作品不变、只配贝斯的声部保护、覆盖取消与确认、精确撤销和重做、成套伴奏按小调和移调生成、当前段以外内容保留、空白作品提示、保存刷新和分享重开、32 小节双格式导出与取消。390 像素视口的设置、摘要和应用操作可用，无整页或工坊内部横向溢出。详见 `project-notes/browser-v0.10.0-validation.json` 与截图。

本轮只生成当前四小节段。长音仍限于单个小节，各段共用整曲音色、速度与调性。规则伴奏不保证适合每一条旋律，应用前可试听比较；实体手机及更多浏览器的长曲性能继续留待后续验证。
