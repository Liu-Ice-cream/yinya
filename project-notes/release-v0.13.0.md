# 音芽 v0.13.0 · 乐句编辑台

把一句旋律连起来看、选中一起改，再继续写成自己的作品。

- 旋律、贝斯增加四小节连续视图，显示逐拍和弦参考及播放位置，保留原单小节积木视图。
- 拖动音符改时间和音高，拖右端调整为 1–8 格；支持框选、Shift／多选、前两小节选择、复制粘贴、统一力度和删除，以及手机操作按钮与网格内快捷键。
- 复制保留音符间距、长短音和力度，目标段音色及配器保留。页面内剪贴内容、选择、写入光标及拖动预览不写入作品。
- 拖动只做临时预览，松开后一次提交。重叠、越界和跨小节长音整次拒绝，已有内容保留；Esc、失焦或作品变化会取消拖动。每次批量修改均可一次撤销和重做。
- 「试听四声部」使用本段配器，在声音实际开始后同步显示播放线；编辑会停止播放。桌面自动适配整段，窄屏在网格内部滑动查看，音高标签保持可见。

继续使用 v11 作品格式和 `yinya.v11.*` 存储键，兼容读取旧作品。结果都是普通音符，v0.12.0 也可读取，保存、分享、JSON 备份和 WAV／MP3 采用原流程。只新增浏览器视图偏好，不改写旧作品，不新增采样包、外部服务或依赖。

207 项测试通过，新增 30 项：原子移动、长度、力度、删除、复制与粘贴、范围／碰撞保护、稳定半音 ID、矩形选择、连续编辑、逆向恢复、冻结 v0.12.0 转换、双采样率 PCM 对照、实际音频起始计时、指针预览／提交／Esc／过期／冲突／触屏分支，以及 32 小节 WAV 和独立 MP3 解码。

浏览器验证了新旧视图切换不改作品、写入光标、复制两小节及粘贴、精确撤销重做、多选保持、真实鼠标拖动／拖尾／框选与碰撞拒绝、贝斯编辑、鼓点原网格、四声部试听播放线。原有 15 首作品保留，新增测试作品保存后共 16 首；32 小节保存刷新、分享重开、MP3／WAV 生成及取消通过。390 × 844 窄屏的整页和面板无横向溢出，内部横向滚动、固定音高标签及批量操作可用。详见 `project-notes/browser-v0.13.0-validation.json` 与截图。

本轮仅编辑当前四小节的单音旋律／贝斯，音符仍限于单个小节；不加入跨小节延音、多音旋律或跨段批量选择。触屏分支有单元测试，窄屏为桌面浏览器模拟，实体手机与更多浏览器的长曲性能仍待验证。
