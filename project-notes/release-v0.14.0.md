# 音芽 v0.14.0 · 连贯乐句

旋律和贝斯支持跨小节长音，乐句能保留完整的持续发音。

- 音符最长 32 格，可从任意格开始跨小节，限定在当前四小节段内。四小节视图显示整条延音，支持整体移动、拖尾、所选时长、复制粘贴、力度和删除；重叠及段落越界整次拒绝，每次修改可一次撤销。
- 「连接同音」连接首尾相接、音高与力度相同的音符；「按小节断开」恢复每小节独立起音。未连接的相邻同音保留各自起音，段落边界和整曲循环不连接。
- 单小节视图点击延音回到原起点并选中整音；删除、清空和八度移动操作相交完整音符。小节复制按边界截取实际发声部分，替换目标处相交整音；整段复制保留延音。
- 点击完整长音、四声部试听、整曲播放与 WAV／MP3 导出采用同一连接关系。钢琴、吉他和拨弦贝斯保留自然衰减；新建的原始波形长音采用持续强度。
- 原创示例「长风入晨」「潮汐低语」，分别展示舒展旋律与持续贝斯。旋律工坊在前句延音跨入续写范围时提示先断开，保护原句；整段生成和保留节奏改音高继续可用。

作品升级为 v12，起点保存完整时长，延音部分不额外保存独立音符。使用 `yinya.v12.*` 存储键，兼容读取旧 v1–v11 并保留旧键。旧作品只迁移格式标记，声音、配器与重复起音保持。v0.13.0 及更早版本不能读取 v12，回退前请保留旧版 JSON 备份。没有新增依赖、音源或外部服务。

225 项自动测试通过，新增 18 项覆盖完整长音校验、连接／断开、单小节操作、段落重排、工坊边界、所有旋律／贝斯音色在 44.1／48 kHz 的连续 PCM 对照、长音点击试听，以及 32 小节 WAV 与独立 MP3 解码。冻结 v0.13.0 转换基准，并保留更早版本的声音基准。

浏览器验证旧 16 首作品保留，新增本版原创测试作品后共 17 首；连接与断开、真实鼠标拖尾及整音移动、重叠拒绝与精确撤销、单小节延音跳回起点、整体删除恢复、32 小节保存刷新及 MP3／WAV 生成。390 × 844 窄屏按钮可操作，页面无横向溢出，网格内部可横向滚动。实体手机仍需后续验证。

每段仍为四小节，整曲 4–32 小节；本轮不增加跨段延音、多音旋律或渐强渐弱曲线。
