# 音芽 v0.15.0 · 动态编曲

每段音乐可以逐渐进入、加强和淡出，让已有旋律、和声与长音有更清楚的起伏。

- 「动态编曲」为本段旋律、和弦、贝斯和鼓点分别设置 0–100% 起始／结束音量，四小节内平滑过渡；提供保持平稳、渐入、渐出、逐渐加强四种模板与曲线。
- 调整只生成临时候选，可比较原版与候选的完整四声部；取消、关闭或 Esc 保留原稿。应用后一次撤销／重做，作品变化时拒绝旧候选覆盖。
- 段落卡片显示变化方向，复制、移动和重复扩展保留起止音量。原有配器滑块可恢复固定音量，重置配器恢复四声部固定 100%；音符、音色与开关保留。
- 长音持续期间也会变化，整曲播放、段落循环、点击试听、分享和 WAV／MP3 都保留渐变。循环重新从本段起始值开始；上一段的自然余音保持其结束增益，不会在下一段重新放大。
- 原创示例「微光渐起」「晚风收声」展示渐入、推进与收尾。

作品升级为 v13，增加四声部的段落结束音量；旧 v1–v12 的结束值等于原音量，保留原来声音。使用 `yinya.v13.*` 存储键，并保留旧键。v0.14.0 及更早版本不能读取 v13，回退前请保留旧版 JSON 备份。没有新增依赖、采样包或外部服务。

249 项自动测试通过，新增 24 项验证端点、曲线、候选生命周期、固定段落、循环、余音、原音符增益与两种采样率。独立计算合成后的音量与限幅器 PCM，验证增益没有改动发音包络；覆盖 32 小节 WAV 及独立 MP3 解码，冻结 v0.14.0 音频转换基准。动态声部按段使用独立乐器实例，最多八个，仍在现有引擎限制内。

浏览器验证旧 17 首作品保留，新增本版原创测试作品后共 18 首；模板和滑块、原版／候选切换、取消及 Esc 无改动、一次应用与精确撤销重做、静音渐入、段落变化摘要、32 小节保存刷新、分享重开与双格式生成。390 × 844 窄屏面板与整页无横向溢出，四个声部及底部按钮可操作。截图与详细检查见本版浏览器验证记录。

首版每段两个端点；相邻段落分别设置起止值，连续过渡需自行对齐前段结束与后段起始。未加入自由曲线、自动变速或跨段长音，实体手机及更多浏览器的长曲性能仍需后续验证。
