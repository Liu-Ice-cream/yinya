# 音芽 v0.1.0

日期：2026-10-06。基于 BeepBox 的首个可运行个人产品版本。

## 结果

用户可从原创起步作品或空白开始，在中文四小节界面中修改旋律、和弦、贝斯和鼓点，循环试听，保存作品，分享快照及另存改编，导入/导出 JSON 备份，并导出完整四小节 WAV。

新增独立音芽界面，复用上游 `Song`、`Synth` 和 `SongRenderer`。原始编辑器源码保留，音芽构建使用跨平台 Node/esbuild 脚本，不要求 Windows 用户安装 Bash。

## 首版功能

- 音芽品牌、中文说明、原创 SVG 标识、浅色绿色界面。
- 三段原创起步作品：晴日发芽、月下散步、像素出发；空白创作入口。
- 旋律、和弦、贝斯、鼓点四层：旋律和贝斯采用五声音阶；鼓点是三个自行设计的合成鼓音；支持开关及音量。
- 四小节网格、60–180 BPM、三种旋律波形、小节复制与清空、撤销和重做。
- 草稿自动保存、命名作品保存与更新、作品库、改编另存。
- v1 快照链接，中文标题编码，分享载入后转为独立草稿，避免刷新覆盖改编内容。
- JSON 备份与导入、严格版本和数据范围校验，异常导入保留当前作品。
- WAV 离线合成导出及明确下载入口；本地地址分享提示。
- 手机布局：四层横向切换，网格区域横向滚动；方向键移动格子焦点。

## 已执行的验证

1. `npm ci --ignore-scripts --no-audit --no-fund`：成功安装 237 个包，保留原有锁文件。
2. 上游 TypeScript 编译检查通过；使用 esbuild 构建原版编辑器，在真实浏览器中确认原版编辑界面正常载入。此处并未执行需要 Bash 的全套上游构建脚本。
3. `npm run build-yinya`：通过。
4. `npm run test-yinya`：7 个测试通过，覆盖中文分享往返、错误输入、音符顺序和边界、WAV 头与采样、三段作品的实际非零 PCM、四声部独立合成与静音、60/180 BPM 下四小节循环边界。
5. 真实浏览器：作品名称与速度修改、格子编辑、撤销/重做、小节复制与清空、声部关闭、存档及刷新恢复、链接载入、改编保存与原作品共存、改编后刷新恢复、有效 JSON 导入、损坏 JSON 拒绝。
6. WAV 实际下载：验收作品 120 BPM；2 个声道、44100 Hz、352800 帧、8 秒、1411244 字节。用 Python wave 模块独立读取并核对。
7. 390 × 844 手机视口：页面无横向溢出；网格可独立横向滚动，第 16 步格子可点击；保存手机及桌面截图。
8. 浏览器未观察到 JavaScript 错误；音频播放位置可持续更新。未做人工听感评分、实体手机或多浏览器长期稳定性测试。

## 当前限制

固定四小节；旋律和贝斯每一步一个音，和弦按整拍编辑，暂不支持任意长度音符、录音采样或音阶切换。当前作品库最多 100 件，不含账号、云端同步、公开社区或实时协作。

音芽 v1 链接及备份不是 BeepBox 历史格式，尚未实现格式间导入转换。当前仅本机运行，分享链接不能直接供其他设备访问；公开部署后可共享。草稿与作品存储按浏览器隔离，多标签页共享作品库并在保存前刷新，但未实现云端并发控制。

WAV 使用上游合成能力生成；保留上游 ScriptProcessor 音频接口，尚未迁移到 AudioWorklet。当前验证不等于实体手机的音频性能保证。
