# 音芽 v0.16.0 · 节奏工坊

鼓点可以连续编辑四小节，也能为同拍的低鼓、小鼓和沙帽分别安排轻重。

- 新增原始、柔和、电子三套本地合成鼓组，支持整曲选择和本段指定。
- 鼓点编辑台支持框选、多选、复制粘贴、跨小节／跨行移动、批量力度与删除；冲突或越界整次取消，每次可一次撤销，手机可滑动并使用按钮。
- 节奏工坊提供六种模板、过门和轻重交替，四声部试听原版与候选，覆盖提示后应用；关闭或取消保留原稿。可只更换鼓组。
- 新增「暖拍漫步」「电光节拍」原创示例。保存、分享、段落复制、WAV 和 MP3 保留鼓组与逐击力度。

作品格式升级为 v14，读取旧 v1–v13 并保留旧存储键及原有声音；旧作品默认原始鼓组、标准力度。v0.15.0 及更早应用不能读取 v14，请保留旧版备份。JSON 备份上限提高至 96 KB，支持完整 32 小节逐击力度；分享上限保持不变。

验证：276 项自动测试，包括冻结旧作品转换、独立逐击 PCM 混合对照、三套鼓组双采样率、候选生命周期、指针取消／过期保护、32 小节 WAV／MP3 及独立解码。桌面与 390px 窄屏交互验证；实体手机和更多浏览器的长曲表现仍需继续验证。
