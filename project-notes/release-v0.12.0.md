# 音芽 v0.12.0 · 段落配器

让前奏、主题、变化和结尾各有自己的乐器搭配。

- 每个四小节段独立选择旋律、和弦和贝斯音色，或跟随整曲。修改整曲音色仅影响跟随它的段落，独立设置保留。
- 四声部各有本段相对音量：100% 保持整曲音量，0% 静音，整曲开关与音量继续生效。音符及长短音、力度保留。
- 段落卡片显示实际配器，侧栏提示本段音色；提供完整四声部试听、停止、重置，以及撤销重做。复制、移动与重复扩展保留配器；新增空白段默认跟随整曲。
- 新增两套十六小节原创示例「晨光接力」「星灯渐远」，分别展示大调与自然小调中乐器、声部和音量的段落变化。
- 点击音符、段落及工坊试听、整曲播放、保存分享与 WAV／MP3 导出使用同一套配器。换段保留正常乐器余音，自然曲尾依据实际发声的乐器计算。

作品升级为 v11，使用 `yinya.v11.*` 存储键，兼容读取旧 v1–v10 并保留旧键。旧作品默认全部跟随整曲，相对音量 100%，保持原有声音；新版本不会自动重写音乐。v0.11.0 及更早版本不能读取新 v11，回退前请保留旧版备份。生成、合成与编码继续在浏览器本地完成，未新增外部服务、采样包或依赖。

177 项自动测试通过，新增 20 项配器验证：严格校验与迁移、冻结 v0.11.0 转换基准、全部音色的实际引擎索引、相对音量与力度／四音和弦校准、静音及全局控制、范围保护、复制重排、工坊保留配器、备份及链接边界、44.1／48 kHz 试听与独立参考 PCM、跨段释放、实际曲尾、取消，以及 32 小节 WAV／MP3 独立解码。

浏览器检查覆盖原有 14 首作品保留与迁移、音符及其他段落保护、整曲与独立音色关系、试听无写入、重置及精确撤销重做、复制配器、32 小节保存刷新及分享重开、WAV／MP3 生成与取消。390 × 844 窄屏面板无横向溢出，可调整音色和音量并试听。详见 `project-notes/browser-v0.12.0-validation.json` 与截图。

每段仍固定四小节，作品支持 4–32 小节。速度和调性继续由整曲控制，长音仍限于单个小节；未加入渐强渐弱曲线、跨小节延音或更多鼓组。实体手机及更多浏览器的长曲性能仍待验证。
