# 音芽 v0.1.2

日期：2026-10-06。重点优化当前四小节的编辑反馈。

## 使用体验

- 暂停时点亮或更换音符，立即试听约 0.32 秒的短音；旋律、贝斯试听单音，和弦试听整组和声，鼓点试听本次点击的鼓声。
- 使用当前声部的 BeepBox 音色与音量，含旋律波形设置。删除音符、关闭声部或音量为零时保持安静。
- 网格右上方增加「点击试听」开关，默认开启。偏好独立保存在当前浏览器，刷新后恢复，不写入作品、分享链接或导出音频。
- 循环播放中编辑直接改变循环，不叠加预听声音。关闭试听开关也不停止整曲播放。
- 连续点击切换到最新音；撤销重做、切换声部/小节、开始播放/导出、关闭试听、进入后台或离开页面会取消未完成的试听。音频权限启动延迟期间，取消仍有效。
- 试听失败时保留编辑，提供中文提示，可再次尝试播放。

长度仍为四小节，v1 草稿/作品库/备份与 WAV/MP3 导出继续兼容。小节扩展已记为未来方向，暂缓。

## 实现

`yinya/preview.js` 使用独立的 BeepBox Synth 合成点击音符，以单一可复用 Web Audio 上下文播放短音；保留主合成器及作品数据，避免改变播放位置或音频导出。短音开头及末尾平滑淡入/淡出，快速点击停止旧音，只允许最新请求启动。

## 验证

- `npm run build-yinya`：通过。
- `npm run test-yinya`：16 项通过，含原有作品与 MP3 解码测试。
- 新增实际 PCM 验证：23 个可点击的旋律/和弦/贝斯/鼓声均生成有限、非零音频；试听音高与导出音符一致，和弦保持完整；不修改作品。覆盖 44100/48000 Hz、60/108/180 BPM、当前音量和波形。
- 控制器测试：静音不打开音频上下文；快速点击只启动最新声音，替换旧声；音频启动等待期间取消有效；作品快照隔离；音频启动失败和缓冲播放失败后可重试，过期失败不干扰后续编辑。
- 真实浏览器：四种声部添加试听、鼓声叠放后只预听新鼓声、删除不试听、关闭试听、设置刷新恢复、声部关闭、音量为零、播放中编辑、试听开关不停止循环、Enter 操作、撤销重做。记录见 `browser-v0.1.2-validation.json`。
- 试听后实际下载 MP3 与 WAV。MP3 独立解码无错误：193097 字节、2 声道、44100 Hz、354816 采样、约 8.045714 秒；WAV 使用 Python wave 验证：2 声道、44100 Hz、16 位、352800 帧、8 秒（120 BPM）。MP3 记录见 `audio-v0.1.2-validation.json`。
- 桌面及 390 × 844 视口中开关可操作，移动页面无横向溢出。截图：`yinya-v0.1.2-desktop.jpg`、`yinya-v0.1.2-mobile.jpg`；未观察到控制台错误或警告。

浏览器验证确认音频播放请求正常启动；尚未进行人工听感评分、实体手机或多浏览器长期测试。
