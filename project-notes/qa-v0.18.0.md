# v0.18.0「和声延展」验证记录

日期：2026-10-22。

## 自动验证

- `npm run test-yinya`：327 项通过，零失败；新增 20 项（18 项长和弦、2 项指针伸缩）。
- `npm run package-yinya`：构建与静态包通过。
- 冻结 v0.17.0 三组作品状态与规范化音频转换哈希；此前 v0.7.0–v0.16.0 基准继续通过，未改写旧 fixture 或哈希。一拍声音转换保持一致。
- v16 时长拒绝缺失、稀疏、非整数、非标准空拍、重叠及跨四小节段；单拍、长和弦编辑、复制、结构操作与工坊保留元数据，失败不改写原稿。
- 19 组和弦的全部转位、2／3／4 拍和五种演奏方式；四款音色与五种方式在 44.1／48 kHz 下合成有限、可听 PCM。
- 齐奏与扫弦在四款音色、两个采样率下，跨小节分割与不分割参考的双声道音频逐采样相同，确认没有小节线处的额外起音。
- 点击长和弦试听包含完整时长；全局静音、实际力度、段落起止音量、自然余音与严格整段循环验证。
- 32 小节长和弦 WAV 长度和最后持续拍、192 kbps 立体声 MP3 独立解码、最后持续拍及收尾验证。
- 稠密 32 小节、60 字中文标题、每段 24 字中文名称及最高音／重力度：分享 18,932 字符（上限 20,000），格式化备份 72,043 字节（上限 98,304）。
- 两首新示例的跨小节和弦、速度、段落结构及对应贝斯根音验证。

## 浏览器实测

- 桌面真实鼠标拖动：4 拍跨小节和弦缩为 3 拍，一次撤销恢复；时长菜单伸长遇后音整次拒绝，原块不变。
- 复制 4 拍和弦、删除目标、指定起点粘贴，时长／转位／轻重保留；连续撤销恢复原和弦。
- 单小节显示「—」延音，点按回到起点；时长菜单修改与撤销生效。和声工坊原版／候选正确显示延音。
- 390 × 844 窄屏：时长菜单及按钮可用，网格独立横向滚动，页面无横向溢出；操作后撤销恢复，视口已重置。
- v0.17 草稿与 20 项本地作品迁移保留；新增一项验证作品后为 21 项，32 小节保存及重载保留跨小节时长。
- 四声部段落试听可启动及停止，无控制台错误。浏览器分别完成完整 32 小节 WAV 与 MP3，出现「下载 WAV」「下载 MP3」入口及完成提示；下载文件保存事件未单独确认，文件格式正确性由独立音频测试验证。

## 范围

每组和弦最长 4 拍，可跨小节但不能跨当前四小节段。长和弦不会自动覆盖后音或截短；没有任意自定义和弦。实体手机、多浏览器与长期循环性能仍待更多设备验证。新格式需 v0.18.0 打开，回退前保留旧版 JSON 备份。
