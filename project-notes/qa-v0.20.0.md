# v0.20.0 主题变奏验证

日期：2026-10-29。

## 实现边界

- 新增 `variation.js` 纯规则及 `variation-workshop.js` 界面，复用已有四声部试听和历史记录。只替换目标段旋律音乐数据，可选开启该段旋律；目标其他声部、整曲设置、音色和动态保留。
- 轻微修饰最多修改 ceil(可改音符数 / 4) 个来源音符的音高，单次音高变化不超过四个半音，节奏与力度保留。无可选音高时跳过。
- 节奏变化最多处理 ceil(可改音符数 / 2) 个来源音符，移动时检查相邻边界；拆音在原时长内留一格休止；无法移动／拆分时尝试缩短，始终保持合法单声部序列。
- 收束只处理后两小节末尾至多两个可改音符。真实末音可改时优先目标当时和弦根音，并延至段末或 32 格上限；根音不在音阶内时选择和弦内的音阶音，没有共同音时优先音阶。保护优先，可能没有变化。
- 前两小节保护含完整跨入后半句的长音及原有空拍；重拍指第 1、3 拍起音。受保护音符保持音高、起点、时长与力度，和目标和弦不一致时提示后由用户试听决定。
- 来源等于目标可以原地变奏；来源为空拒绝，完整保留目标。候选只在本页面存在，未应用时不写入保存或导出。收束是固定规则候选，不提供无效的「换一版」。
- 保持 v16 作品格式与存储键，`model.js`、旧格式迁移及合成器未修改。

## 自动验证

- `npm run test-yinya`：366 项通过，0 失败；原 346 项回归加 20 项变奏测试。
- 覆盖三种方式、确定性候选、改动数量限制、完整长音／空拍保护、目标跨小节和声、音域端点、三种音阶、跨段隔离、显式启用与整曲静音、32 小节分享／备份往返。
- 事务测试覆盖具体覆盖提示、取消、候选过期、作品过期、关闭及导出禁用；空目标无需覆盖提示，重复确认只应用一次。
- 试听错误可重试，旧请求回调失效，自然结束恢复按钮。44.1／48 kHz 试听缓冲与独立目标段渲染逐样本对照，峰值误差门槛 1e-6，RMS 误差门槛 1e-7；本次实测最大差异约 3.73e-9，属于浮点尾数误差。
- 变奏写入第八段后渲染完整 32 小节，WAV 声道与长度正确；MP3 经独立 mpg123 解码无错误，双声道、完整长度及末段有声均通过。
- `npm run package-yinya`：静态包构建通过。发布前对全部已暂存源码、说明和截图执行 `npm run check-privacy`；CI 继续执行 Linux／Windows 全套检查。
