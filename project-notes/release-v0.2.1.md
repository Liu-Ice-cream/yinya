# 音芽 v0.2.1：让旋律有长有短

旋律可以选择 1、2、4、8 格时长。点空格添加，点色块选中整音，再调整长度或删除；长音连续显示，小圆点标记起点。

- 延长遇到后音或小节末尾自动收短，保留后面的音符；在长音中间插入新音高会结束前音。
- 支持删除按钮、Delete / Backspace、撤销与重做。
- 点击旋律试听实际时长，复制小节、整段复制、重复扩展、保存、分享及 WAV / MP3 导出保留长音。
- v3 作品格式兼容旧 v1 / v2，旧相邻短音仍分别发音。新存档使用 `yinya.v3.*`，保留旧存档键；旧版本无法读取新 v3 作品，回退前请保留 JSON 备份。

35 项自动测试通过，包含边界与重叠处理、旧格式迁移、真实合成器试听时长、十六小节末段长音 WAV / MP3 导出及独立 MP3 解码。浏览器验证编辑、删除、撤销重做、复制、存档、分享和手机宽度布局。

当前长音只开放旋律，限制在单个小节内；贝斯、跨小节延音、力度与更多乐器音色留待后续。窄屏检查使用浏览器模拟尺寸，实体手机仍需后续验证。
