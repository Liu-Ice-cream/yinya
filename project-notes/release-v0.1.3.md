# 音芽 v0.1.3

日期：2026-10-07。继续优化四小节音乐积木的播放与编辑体验。

## 使用体验

- 「跟随播放」默认开启，网格随实际播放位置自动切换小节，第 4 节结束后回到第 1 节。
- 小节按钮分别用绿色表示编辑位置、金色表示播放位置，网格高亮当前步与拍，并显示当前小节和拍数。
- 播放中手动选节，暂时停住编辑视图，音频继续循环；「回到播放位置」恢复跟随，只切换视图，不跳转音频。
- 暂停后重新播放会恢复临时停掉的跟随；主动关闭开关会保存偏好，刷新或重新播放仍保持关闭。与点击试听设置共同保存，不进入作品、分享链接或音频文件。
- 切换小节保持网格键盘焦点。复制到下一节会留在目标小节，撤销/重做仍可使用。

作品仍为四小节，草稿、作品库、分享及 JSON 格式保持 v1，WAV / MP3 导出继续兼容。长度扩展暂缓。

## 实现

`yinya/playback.js` 维护跟随视图状态，区分长期偏好和本轮手动查看；不操作合成器或作品数据。界面按播放步更新进度，小节变化时重绘网格，小节按钮保留 DOM 及焦点。进度使用 timer 且关闭实时朗读，避免每步播报干扰操作。

## 验证

- `npm run build-yinya` 通过；`npm run test-yinya` 共 20 项通过，包含已有试听和独立 MP3 解码测试。
- 新增 4 项跟随测试：步/拍换算及循环边界、暂停时保留编辑选择、手动查看跨循环保持、恢复跟随及持久关闭偏好。
- 真实浏览器验证自动切换、第 4 节到第 1 节、旋律/和弦/鼓点的当前步和拍高亮、手动视图跨循环保持、一键返回、暂停清除高亮、重新播放恢复临时跟随、网格方向键焦点、复制/撤销/重做、暂停点击试听，以及两项偏好共同保存并在刷新后恢复。记录见 `browser-v0.1.3-validation.json`。
- 播放中导出会暂停音频并清除播放高亮。实际下载 120 BPM 起步作品的 MP3 与 WAV：MP3 为 193097 字节，独立解码无错误，44100 Hz、双声道、354816 采样、约 8.045714 秒，末节有音频；WAV 为 1411244 字节，44100 Hz、双声道、16 位、352800 帧、8 秒。记录见 `audio-v0.1.3-validation.json`。
- 桌面及手机布局（请求 390 × 844 视口，浏览器报告内容宽度 375 px）中跟随开关与返回按钮可操作，页面无横向溢出。截图见 `yinya-v0.1.3-desktop.jpg`、`yinya-v0.1.3-mobile.jpg`；浏览器未报告错误或警告。

本轮验证使用本机 Chromium 浏览器。人工听感评分、实体手机、多浏览器及长期循环测试仍待后续开展。
