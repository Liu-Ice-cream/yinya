# 音芽 v0.2.0：让音乐长成一首小曲

作品长度支持 4、8、16 小节。选择追加空白或重复已有内容，每四小节分组编辑；整段复制可以一起复制旋律、和弦、贝斯与鼓点，再修改后半段。

- 播放跨段自动跟随，保留手动查看及回到播放位置。
- 缩短有音符的作品、覆盖非空段落时先提示，支持撤销和重做。
- 本地保存、分享链接、JSON 备份、WAV / MP3 导出使用完整作品长度。
- v2 作品格式兼容读取旧 v1 草稿、作品、分享链接和备份；新存档使用独立键，保留旧存档。旧版不能读取新 v2 作品，回退前请备份。

120 BPM 下，4、8、16 小节分别为 8、16、32 秒。默认仍为四小节，32 小节留待后续验证。

验证：29 项自动测试通过，包含真实合成器循环边界、4 / 8 / 16 小节 WAV 与 MP3 长度、末小节声音和独立 MP3 解码；浏览器完成长度调整、复制、确认保护、撤销、存档、分享及 MP3 Worker 验收，检查桌面与手机宽度布局。实体手机与更多浏览器仍在后续验证范围中。
