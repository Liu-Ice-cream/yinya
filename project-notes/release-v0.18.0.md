# 音芽 v0.18.0 · 和声延展

和弦可以持续 1–4 拍并跨小节，钢琴与吉他伴奏更有空间。

- 四小节和弦编辑台按时长显示块宽，拖右侧手柄伸缩，或用菜单批量设置。移动、复制、替换保留完整时长与表达；冲突或越过当前四小节时整次拒绝，每次可一次撤销。
- 齐奏与扫弦持续，跨小节不重复起音；分解、舒展分解和短奏维持原有每拍节奏。点击试听、段落试听、主播放及 WAV／MP3 使用相同规则。
- 单小节显示延音，点击可回到起点；清空移除相交完整和弦，复制小节截取可听部分并保护目标长和弦。和声工坊保留时长，旋律／伴奏工坊及乐句参考识别跨入和声。
- 新增慢速示例「雾中晨光」「海岸晚风」，进入「和弦」层与「四小节编辑台」体验。

作品格式升级为 v16，兼容读取旧 v1–v15；旧和弦默认一拍，原有转位、力度与声音保留，旧存储键保留。v0.17.0 及更早应用无法读取新格式，回退前保留旧版 JSON 备份。单组最长 4 拍，不能跨四小节段。

验证：327 项自动测试，包括冻结旧作品转换、原子修改与指针取消、全部和弦与转位、四款音色／五种演奏方式双采样率、跨小节与不分割参考的逐采样音频对照、32 小节 WAV／独立 MP3 解码。桌面及 390px 窄屏交互验证；实体手机及更多浏览器的长曲性能仍需验证。
