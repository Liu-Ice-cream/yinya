# 音芽 v0.6.0：让贝斯连成一条低音线

贝斯支持 1、2、4、8 格长音，4 格一拍、8 格两拍。点空格添加，点色块选中整音后调整或删除，方向键移动、Delete / Backspace 删除，支持撤销和重做。旋律与贝斯分别记住新音符长度。

- 插入新音高会结束前音；延长遇后音或小节末尾自动收短，保留后音并显示实际长度。
- 贝斯点击试听实际时长；完整播放、复制、长度扩展、存档、分享、JSON 备份和 WAV / MP3 保留长音。
- v7 格式兼容旧 v1–v6。旧贝斯保持原来的短音与逐音起音，保留既有旋律时长、音色与和弦演奏方式；新存档使用 `yinya.v7.*`，保留旧键。旧版无法读取新 v7 作品，回退前请保留 JSON 备份。
- 备份导入上限为 32 KB，容纳十六小节作品增加贝斯时长后的完整 JSON 数据。

71 项自动测试通过，包含旧格式迁移、插音与边界、音域和速度／采样率边界、真实试听与导出对照、循环边界、取消、4／8／16 小节 WAV / MP3 和独立解码、32 KB 导入边界。浏览器验证长音编辑、撤销、删除、复制、保存刷新、分享、音频导出、大备份导入及手机宽度布局。

长音仍限于单个小节；贝斯继续沿用原有方波音色。实体手机和更多设备试听继续留待后续验证。
