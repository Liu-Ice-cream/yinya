# 音芽 · v0.4.0

面向零基础用户的音乐积木。基于 BeepBox 的合成器，通过旋律、和弦、贝斯和鼓点四层音乐，创作一段自己的短曲。

## 开始创作

先按 [README](README.md) 安装并启动项目，再打开 `http://127.0.0.1:9093/yinya/`。Windows 安装依赖后可双击根目录的 `启动音芽.cmd`。命令行服务器也可通过 `YINYA_PORT` 指定其他端口。

1. 选择「晴日发芽」「月下散步」或「像素出发」，也可以从空白开始。
2. 在「作品长度」中选择 4、8 或 16 小节；扩展时可追加空白或重复已有内容。每四小节一组，用上方段落按钮切换。
3. 旋律先选 1、2、4、8 格时长，再点空格添加。点已有色块选中整音，可调整时长、按「删除音符」或在色块上按 Delete / Backspace 删除；小圆点标记起点。暂停时试听所选旋律的实际时长，新和弦音色试听实际一拍和余音；原有圆润和弦、贝斯、鼓点保持约 0.32 秒试听。按「播放循环」听完整作品。
4. 播放时网格自动跟随当前小节；手动选择任意一节即可暂停跟随并继续修改。旋律和贝斯使用 C 大调五声音阶。
5. 调整速度、音量、音色与声部开关；修改可以撤销和重做。
6. 用「复制整段」将当前四小节的全部四声部复制到另一组。覆盖已有内容及缩短有音符的作品时先提示，之后可以撤销恢复。
7. 保存到「我的作品」，通过分享链接发送作品快照，或导出 MP3、WAV 和 JSON 备份。

旋律音色有六种：柔软三角波、圆润波形、复古方波、钢琴、电钢琴和木吉他。后三种为合成音色，分别由 BeepBox 的钢琴、FM 电钢琴、钢弦吉他预设调校而来，不加载外部录音包。新音色已按相同音高与时长组合做 RMS 能量校准；这不等于所有音符在不同设备上的主观响度完全一致。

和弦音色可独立选择圆润波形、钢琴、电钢琴、木吉他，旋律与和弦可以自由搭配。新和弦音色按同时发声的三音调校伴奏强度，保持原有和弦音高及每拍节奏。木吉他目前为三音同时拨响。

在旋律或和弦层选择「试听声部」：仅旋律，或旋律＋和弦。点击试听按钮只听当前四小节组，按钮旁显示范围；再次点击停止。双声部模式尊重各层开关和音量，可以在旋律静音时单听和弦，贝斯与鼓点不加入段落试听。切换音色后可用同一旋律比较，不会改变音符、音量或其他声部。所选试听声部均关闭、音量为零或当前段落没有对应音符时，按钮不可用；「点击试听」开关只控制点格子的单音，不影响主动试听段落。开始试听会暂停完整循环；切换声部/小节、编辑、撤销/重做、开始播放/导出或切到后台会停止试听。

「点击试听」开关在网格右上方，默认开启，设置只存在当前浏览器，刷新后仍生效。关闭后可安静编辑；删除音符、关闭声部或音量为零时不试听。循环播放中编辑直接改变音乐，避免额外声音叠加。快速点击切换到最新音，切换声部/小节、撤销重做、开始播放/导出和离开页面会取消未完成的试听。

旋律 4 格为一拍，8 格为两拍。长音仅在当前小节内；添加或延长遇到后面的音符、小节末尾，会自动收短并显示实际格数，保留后音。在长音中间点另一个音高，会在点击位置结束前音并开始新音；删除后音不会自动延长前音。相邻同音高的两个起点仍分别发音，旧作品不会被自动合成长音。选择时长同时设定后续新音符的长度；按「取消选择」后可用该长度继续添加。

「跟随播放」默认开启。小节按钮用绿色标记当前编辑小节，金色标记正在播放小节；网格同时高亮当前步和拍，显示播放进度。播放中手动选节会临时暂停跟随，音频继续循环；点击「回到播放位置」恢复跟随，不改变音频位置。暂停后重新播放会恢复临时停掉的跟随。主动关闭开关则会保存该偏好，刷新或再次播放仍保持关闭，点击试听偏好也继续保留。

「导出 MP3」完成后点击「下载 MP3」，获得 44.1 kHz、192 kbps 立体声文件；适合日常分享与播放。需要未压缩音频时，按「导出 WAV」后点击「下载 WAV」，获得 44.1 kHz、16 位立体声 PCM。

两种格式都导出当前作品的完整 4、8 或 16 小节。120 BPM 下音乐分别为 8、16、32 秒，MP3 因编码延迟和补齐会略长。「导出结尾」默认自然收尾：旋律或和弦的新乐器余音越过曲尾时，取两层所需的较长释放时间，最多约 0.58 秒；已有休止足够时不再追加。选「整段循环」严格按小节长度截取，新音色在末尾做短淡出。原有三个波形的导出长度及声音保持兼容。

段落试听、单音试听和导出均使用同一套音色定义与发音参数。合成和编码均在浏览器本地完成，编码器随项目保存，不使用外部音频服务。导出时显示进度，也可按「取消导出」；取消或失败不会丢失作品。

作品存在当前设备、当前浏览器和当前网站地址下。改用其他域名或端口时，先导出 JSON 备份，再到新地址导入。草稿会自动保存，命名作品需按「保存作品」。清理浏览器数据会移除本地作品，建议保留 JSON 备份。通过「另存改编」或分享链接载入的作品，保存时创建新版本。

当前链接为本机预览地址；公开部署之后朋友才能从其他设备直接打开。音芽分享链接和 JSON 使用自己的 v5 作品格式，兼容读取旧 v1 / v2 / v3 / v4 作品，当前不直接导入 BeepBox 的历史链接或 JSON。

## 开发与检查

需要 Node.js 24 和 npm。音芽构建无需 Bash；上游原有脚本继续保留。

```powershell
npm ci --ignore-scripts
npm run build-yinya
npm run test-yinya
npm run start-yinya
```

如果 npm 默认缓存目录不可写，可以在项目中指定临时缓存目录：

```powershell
npm ci --ignore-scripts --cache .npm-cache
```

构建入口 `scripts/build-yinya.mjs` 将界面、BeepBox 合成器及上游 WAV 渲染器打包到 `website/yinya/assets/app.js`。同时生成独立的 MP3 Worker（`assets/mp3-worker.js`），运行时引用原样保存的 `vendor/lamejs.js`。运行服务器仅绑定 `127.0.0.1`。可设置 `YINYA_PORT` 环境变量修改命令行服务器端口；双击启动器使用 9093。

- `yinya/model.js`：作品结构、原创起步作品、校验、分享编码和音频数据转换。
- `yinya/voices.js`：固定版本的六种旋律和四种和弦音色、纯数据预设及独立能量校准参数。
- `yinya/render.js`：带静音尾段的音频渲染、自然收尾和四小节旋律或旋律＋和弦快照。
- `yinya/app.js`：中文编辑界面、本地存档、分享、导入导出与音频调度。
- `yinya/mp3.js`、`mp3-worker.js`：PCM 到 MP3 的适配及后台编码。
- `website/yinya/`：页面、样式、标识、独立编码器与许可证。
- `yinya/preview.js`：使用实际 BeepBox 音色合成短音、管理 Web Audio 播放与取消。
- `yinya/playback.js`：播放进度与自动跟随视图状态，不修改音乐或跳转音频。
- `tests/`：作品数据、实际 BeepBox 音频引擎、试听、跟随与独立 MP3 解码、长曲和长音、音色能量、曲尾及旧作品兼容测试（54 项）。
- `scripts/package-yinya.mjs`：生成仅含音芽运行文件与许可证的静态网站包。
- `.github/workflows/yinya-ci.yml`：Linux / Windows 的安装、测试、构建和网站包检查。
- [部署说明](docs/DEPLOYMENT.md)：静态网站包及部署验收。
- [版本变化](CHANGELOG.md)：已完成的功能。
